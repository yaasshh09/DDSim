# Decisions and known deviations

Two tables. The first is every decision that affects a result, with the reason
it was made. The second is every place this code knowingly disagrees with a
reference or with one of its own docs, with the reason it is not a bug.

Both are load-bearing. Tests cite rows here to justify what they assert, so a
row that changes has to be traced into the tests that lean on it. Never silently
reverse a decision; add a new dated row instead.

The running session narrative lives in PROGRESS.md, which is local and not part
of the repo. This file is the part that a reader of the code needs.

| 2026-08-21 | device/doping.py and device/equilibrium.py added to the layout | docs/03-architecture.md names neither. Profiles do not belong inside builder.py, and the equilibrium driver has to live outside solve/ to keep that package free of semiconductor knowledge |
| 2026-08-21 | Gummel freezes the SRH denominator rather than using the exact tangent | Writing R as c*n - g with c = p/D and g = n_i^2/D keeps both coefficients non-negative. The continuity matrix is an M-matrix, so a non-negative right hand side means the solved density cannot go negative. The exact tangent dR/dn has no such guarantee. Both forms are exact at the current iterate, so the converged fixed point solves the true equation either way. The exact derivatives are implemented and tested, for Phase 3 |
| 2026-08-21 | Terminal current comes from the continuity residual at the contact node, not the adjacent edge flux | The residual at a contact is exactly the current that has to be injected there. Written that way, the recombination in the contact half cell cancels between the two carriers, and the terminal currents sum to zero identically rather than approximately |
| 2026-08-21 | Dirichlet eliminates the column as well as the row | Row replacement alone leaves the pinned unknown coupled into its neighbours, so the factorization mixes it with the rest of the solution. Measured: a density pinned to +1e-6 came back as -1.02e-6. See the Broke entry |
| 2026-08-21 | Contact densities are imposed on the solved profile, not accumulated through it | old + update cancels when the two are far apart, and on the first forward biased cycle they are thirteen decades apart. Imposing a value that was known before the solve is what a Dirichlet condition means; it is not clamping, and no interior node is touched |
| 2026-08-21 | newton_solve takes an explicit residual scale for warm starts | A threshold relative to the initial residual is unreachable when the solve starts at the answer, which is what every Gummel cycle after the first does. The Poisson block passes the doping charge in the largest dual cell, which does not depend on the starting iterate |
| 2026-08-21 | Density convergence measured as max abs(dn) / (n + n_i) | A pure relative change is dominated by nodes where the density is 1e-15 and physically irrelevant; an absolute change is dominated by the majority carrier. The floor at n_i is 1 in scaled units and says that a carrier below the intrinsic density carries no charge worth converging |
| 2026-08-21 | The Scharfetter lifetime is evaluated on abs(net doping) | It wants the total Na + Nd and only the net is available from a composed profile. The two agree everywhere except in compensated material, and nothing here is compensated yet |
| 2026-08-21 | The ideality crossover is demonstrated on a 1e18 device, not the 1e16 one | At 1e16 with the documented lifetimes the diode is diffusion limited and its ideality is 1 above 50 mV, which is correct rather than a shortfall. Depletion recombination has to dominate somewhere for n = 2 to exist, and raising the doping does that by cutting minority injection and raising the recombination rate at once. Nothing else changes between the two |
| 2026-08-21 | newton_solve gives up once the residual is frozen to the last bit and the update is already inside tolerance | Both criteria still have to pass and the result is still converged=False, so the outcome is unchanged and only the iteration count moves. The check runs after the convergence test, so a warm start that arrives with a frozen residual and a zero update is still reported as the success it is. A frozen residual under a still moving iterate is deliberately not caught: that is a solver taking real steps that happen not to help, which is a different failure and gets the whole budget. Verified bit for bit inert on psi, n, p and the terminal currents at seven biases |
| 2026-08-21 | extract/params.py and device/transport.py and device/state.py added to the layout | docs/03-architecture.md names params.py and puts ideality extraction in it. transport.py is the Gummel wiring, which cannot live in solve/ without breaking the module boundary. state.py holds DeviceState, which both equilibrium.py and transport.py return |
| 2026-08-22 | The coupled dF_psi/dpsi carries no Boltzmann charge term | In Phase 1 n and p are functions of psi, so the diagonal picks up (n + p)*volume, which is what makes that matrix an M-matrix. Coupled, they are separate unknowns and the same physics lives in dF_psi/dn = +volume and dF_psi/dp = -volume. Carrying it in both places is the most natural way to get this wrong, because the Phase 1 Jacobian is sitting right there to copy from, and Newton would still converge, slower, to the right answer. The block verification catches it and nothing else does |
| 2026-08-22 | The coupled Jacobian uses the exact SRH tangent, not the Gummel frozen denominator | The frozen form exists to keep the continuity matrix an M-matrix so a solved density cannot go negative. The coupled matrix is not an M-matrix under any linearization, so that guarantee is not available to give up. Positivity comes from damping psi instead. Measured: the two give residual histories identical to three significant figures on a 1e16 diode at 0.8 and 1.0 V, so the exact tangent is not bought for convergence, it is bought for being right |
| 2026-08-22 | The coupled system is row scaled by equation family before the solve | One residual threshold cannot serve a charge and a current. The Poisson rows are order N*volume and the continuity rows are order (D/h)*n, six decades apart on a 1e16 device, so a single max abs(F) is set by the larger and declares Poisson converged a million times above its own floor. Each family is divided by the largest single term that goes into it. It is a diagonal left preconditioner, so it changes no answer, and it is applied outside the assembly so the Jacobian the block verification checks is the unweighted one |
| 2026-08-22 | The coupled update is measured per family, absolutely on psi and relative on the densities | max abs(dx) over the raw vector cannot fall below 1e-9 when n is 1e6 in scaled units, so no threshold suits both. docs/02-numerics.md already asks for the carrier change as max abs(dn)/(n + n_i). The floor at n_i matters as much as the ratio: without it the measure is dominated by nodes where the density is 1e-15 and carries no charge |
| 2026-08-22 | Only psi is damped in the coupled Newton, and the psi sub-vector is scaled rather than clipped entry by entry | Both docs/02-numerics.md and docs/05-pitfalls.md prescribe capping psi and taking the full n and p updates. One factor over the whole vector would be set entirely by the density update and would freeze psi. Within psi the direction is preserved, so the rotation is only between psi and the densities and only while the cap is active |
| 2026-08-22 | physics/bernoulli.py grew a complex branch, in production rather than in the test tree | phases/PHASE-3.md makes complex step verification a permanent CI requirement, so a residual that survives a complex argument is a property the code has to have, not test scaffolding. The real path is untouched: one dtype test per call and every array on it is still float64 |
| 2026-08-22 | solve/newton.py takes a limit callable and an update_norm callable rather than learning about components | Both are the same shape of problem: a scalar rule that cannot express a system whose unknowns differ by decades. Injecting them keeps solve/ free of semiconductor knowledge, which the import graph test enforces |
| 2026-08-22 | Phase 3 scope item 8, symbolic factorization reuse, is dropped rather than attempted | Phase 0 already measured it. scipy exposes no symbolic and numeric split, and the standard workaround gives 6.1x fill and a 46x slowdown in 2D. Nothing has changed since. The interface still lets a UMFPACK or KLU backend deliver it later |
| 2026-08-22 | The row scale is measured at every iterate, not frozen at the starting guess | "Does not depend on the starting iterate" means it must not depend on how converged the start is. It does not mean freezing it. The terms a residual is built from are a property of the state, and on a forward biased junction they grow with the injected density: 28 times between guess and answer on a 1e16 diode at 1 V, 660000 times on a 1e20 / 1e14 one. The threshold itself never moves, at residual_rtol against a scale of one; what is re-measured is the question |
| 2026-08-22 | The Poisson term scale counts the carriers, not only the doping | The residual carries -(p - n + N)*volume, and on intrinsic material that sum is exactly zero while n*volume and p*volume are a dual cell each. A scale built from the doping alone is zero there and every row divides by it. An undoped bar returned a residual of nan and a message blaming the LU factorization for being singular |
| 2026-08-22 | Arora mobility is opt in, and the constant model stays the default | Every Phase 1 and 2 number was taken with the constant model, and Arora moves the current by five percent even at doping too low for it to be doing anything, because its N -> 0 limit is 1340 rather than the tabulated 1417. Making it the default would silently invalidate every measurement already in this file |
| 2026-08-22 | Mobility is averaged from nodes to edges arithmetically | Scharfetter-Gummel derives its edge flux assuming the coefficients are constant along the edge, so one value per edge is what the scheme asks for and the only question is which. The mean is the honest reading of a quantity that is genuinely varying, and on a mesh graded to a junction the two endpoints sit in nearly the same doping anyway |
| 2026-08-22 | Auger is opt in as well, and off by default | It changes nothing measurable below high injection, and the same argument about invalidating recorded numbers applies. Its exact tangent is also not sign definite, unlike the SRH one, so turning it on by default would quietly remove a property the Gummel path documents relying on |
| 2026-08-27 | A carrier flux crosses only the semiconductor share of an edge's face, carried on the geometry beside the permittivity | The zero charge volume in an insulator kills the terms the equations integrate, and a flux is not one of those. Without a separate face, the edge running from the silicon surface into the oxide still moves electrons into a node whose density is pinned at zero, which is a perfect sink bolted to the channel of every MOSFET. The share is the same area weighting the permittivity gets, so an edge along the interface offers half its face, and on a single material device it is exactly 1.0 and every recorded number is unchanged |
| 2026-08-27 | The coupled Newton path takes its mesh, its charge volume and its edge geometry from the device rather than assuming a line | Phase 4's current continuity criterion could not run at all while no device had solved transport on a Mesh2D. Nothing about box integration is 1D; only the wiring was. The Gummel path is still 1D, slices edges contiguously and says so |
| 2026-08-27 | An insulator node's two continuity rows are pinned at zero density, and its Poisson row is left alone | With no charge volume and no carrier face those rows read 0 = 0, and a singular matrix is not something to discover inside a factorization. Zero is also the true statement: an insulator holds no free carriers. The Poisson row is a Laplacian and wants no help |
| 2026-08-27 | A terminal current is the residual summed over every node the contact covers | A plate is one piece of metal, so the current into it is the current into all of it. A point contact is that sum over one node, which is why there is no 1D branch. Reading one node of a plate leaves most of the current unaccounted for and the terminal currents stop summing to zero |
| 2026-08-27 | current_densities divides the edge flux back by the carrier face, and reports exactly zero where that face is zero | The flux kernels multiply by the face because that is what a continuity equation wants. In 1D the face is exactly 1.0, so the quantity was a density by accident and the division is exact. In 2D it is not, and a number named a density has to be one |
| 2026-08-27 | The README C-V figure is benchmark 4, the 5 nm capacitor, not the 10 nm device the analytic tests use | Phase 4's definition of done asks for the curve overlaid on DEVSIM's, and golden data exists for 5 nm and 20 nm only. The analytic table stays on the 10 nm stack, where the doping sweep lives. Both are the same code path |

| 2026-08-27 | A doping profile is called with a Coordinates carrying x and, on a grid, y, and a bare array still means x | Phase 5 is the first thing in this project whose doping varies with depth. Making the second axis a new argument would have changed every profile ever written; making it a container that a bare array falls into changes none of them. Verified bit for bit on all five benchmark devices, so DEVSIM regressions 1 to 5 measure the same numbers they did before |
| 2026-08-27 | The source and drain implant is separable, an erfc edge along x times a Gaussian in depth | A real two dimensional diffusion is not separable, and the difference lives in the corner where the lateral and vertical fronts meet. What the device is actually sensitive to is where the junction sits: the depth under the contact and the encroachment under the gate edge, and both of those are on an axis where the profile is exact. Being separable is also what makes them closed form, so a test can assert the junction depth and the lateral diffusion against the numbers asked for rather than against a previous run |
| 2026-08-27 | The gate electrode covers the channel span exactly and the oxide over the source and drain has no electrode on it | This is the ideal structure: no gate overlap, so no overlap capacitance and no gate induced drain leakage. Both are real effects and both would be additions to the geometry rather than to the physics, so leaving them out costs nothing that this phase is measuring. The uncovered oxide takes the natural condition, dpsi/dn = 0 |
| 2026-08-27 | The source and drain contacts stop short of the gate mask edge, by contact_length being less than sd_length | A contact pins psi, n and p. One running up to the metallurgical junction pins the junction itself, and the built in potential stops being something the solver works out. The builder refuses the geometry rather than solving it |
| 2026-08-27 | The NMOS carries no halo implant, no lightly doped drain and no fixed interface charge | Every one of the three exists to move a threshold voltage or to soften a field. On a phase whose success criterion is that short channel effects emerge without fitting, adding a feature whose purpose is to counteract one of them would make the result unreadable |

| 2026-08-28 | Caughey-Thomas reads the potential drop along the edge, not the magnitude of a nodal field vector | The field a carrier crossing an edge sees is the component along that edge, which on a box integration mesh is exactly the X the Scharfetter-Gummel argument already carries. Reconstructing a vector at a node and taking its length instead gives one field to every edge leaving that node, and on a mesh graded from 2 nm to 200 nm at a junction those edges do not see the same field. It also gives the mobility a value at a node, where a field does not have one |
| 2026-08-28 | Field dependent mobility is opt in through field_dependent, and stays off by default | The same argument that keeps Arora and Auger opt in. Every number recorded in this file before today was taken without it, and the None branch in the Jacobian means a solve without it does exactly the arithmetic it did before the model existed rather than adding a zero |
| 2026-08-28 | The absolute value inside Caughey-Thomas is written as sqrt(X*X), and only on the complex branch | abs() of a complex number is its modulus, which is not holomorphic, so a residual containing one returns an imaginary part of zero and the block verification would report every field dependent term as missing rather than as wrong. Same shape as the complex branch in physics/bernoulli.py and there for the same reason. The real path stays np.abs, because squaring first would underflow to zero and overflow to infinity at the ends of the range |
| 2026-08-28 | dD/dX enters the Jacobian as the flux over D times the tangent, written out rather than as D times dlnD/dX | The logarithm form is shorter and divides by a diffusivity the model is allowed to drive small. The two flux derivative blocks each gain one term and no block gains a new sparsity pattern, because the drop across an edge depends on the same two nodes the flux already did. Measured: mutating either term out fails the complex step block verification at the perturbed state |
| 2026-08-28 | The Gummel blocks lag the field dependent diffusivity at the potential of the cycle rather than carrying its tangent | A Gummel block solves one continuity equation with psi held fixed, so within the block the field is a constant and the diffusivity with it, which is what lagging a coefficient means and what the cycle already does to everything else it holds. At the fixed point the frozen diffusivity is the converged one, so the decoupled path solves the same equations the coupled one does. What is given up is a rate of convergence, not an answer |

| 2026-08-29 | Surface mobility is the enhanced Lombardi, with DEVSIM's own parameters | docs/01-physics.md names Lombardi and gives no parameters, and docs/06-constants.md has none either, so they had to come from somewhere. DEVSIM ships the Darwish variant in its Klaassen.py and DEVSIM is what tier 4 regresses against, so matching the model the reference actually runs is what gives benchmarks 6 to 9 a chance of agreeing. It is the 1988 model with the roughness exponent made a function of carrier density rather than fixed at 2. A test pins all eight parameters per carrier against the reference's source |
| 2026-08-29 | E_perp is the field normal to the interface, taken as the y derivative on the tensor mesh, and it is a magnitude averaged from the signed nodal field | The interface in every device here is a horizontal line on a tensor product mesh, so the normal direction is y and DEVSIM's general triangle machinery buys nothing. The absolute value is taken after the averaging, not before: where the field reverses across a node the field at that node really is near zero, and averaging magnitudes would report the average of two large ones at exactly the places a device has a potential well. A boundary row averages the one edge it has, not two |
| 2026-08-29 | The surface correction is frozen inside a Newton solve and made a fixed point by an outer loop | For a horizontal channel edge the normal field lives on the vertical edges above and below its endpoints rather than on the edge itself, so carrying its tangent would widen the Jacobian stencil past the edge based pattern every assembly in discretize/ is built on. Frozen, the residual and the Jacobian come from the same mobility, so they agree exactly and the nine block complex step verification is untouched, which phases/PHASE-3.md makes a permanent CI requirement. At the fixed point the mobility the solve used is the one the answer implies, so the converged state solves the true equations. Measured: re-solving from the answer with the mobility it implies costs zero Newton steps and returns psi, n and p bit for bit identical. Two or three sweeps on a 1 um NMOS |
| 2026-08-29 | An exhausted surface sweep budget is reported as not converged, even though the last Newton solve converged | What has not converged is the fixed point between the mobility and the state it is read from, and the inner result would claim a convergence the solve does not have. The reported iteration count and both histories are summed over the sweeps, so the residual history carries one sawtooth per refresh, which is the honest picture of the method rather than a defect in it |
| 2026-08-29 | The surface correction is applied at semiconductor nodes only, and the doping it reads is floored at n_i | An insulator has no surface mobility, and it has exactly zero doping, which the roughness exponent raises to a negative power and returns an infinity for. Not harmless if left: an edge from the interface into the oxide averages its two ends, so the infinity reaches the interface row, which is the channel. The floor is the separate half of the same problem and says that below the intrinsic density there are no scattering centres left to count |
| 2026-08-29 | A cold solve with velocity saturation is walked up to it through the low field models | The Poisson guess is not in the basin of a Caughey-Thomas solve on a MOSFET. Measured on a 1 um NMOS: 60 iterations with 55 of them against the step limiter and no convergence, against six from the low field answer and zero at the off state, where the field dependence changes nothing because no current flows. It is continuation in the model rather than in the bias and it is the same shape as the Gummel prelude beside it. Surface scattering needs no prelude: it is outside the Jacobian and only scales the mobility by a few, and the same device cold starts through it in six steps |
| 2026-08-29 | A current is read with the diffusivity the answer implies, not the one the models were built with | For a field dependent mobility this was already true and said so. For a surface corrected one it was false: the models as built carry the uncorrected bulk mobility, and the correction only ever existed inside the solver. Measured on an inverted 1 um NMOS, the terminal currents summed to 7.4e-6 of the drain current with the stale diffusivity against 7.6e-7 with the right one |
| 2026-08-29 | A surface corrected solve's terminal current sum is bounded by residual_rtol rather than by machine precision | The last sweep of a fixed point starts from the previous sweep's answer, so Newton stops the moment it crosses the threshold instead of running into its quadratic tail, and the residual it stops at is the threshold. Measured on an inverted 1 um NMOS: 7.6e-7 of the drain current at the 1e-10 default, 1.2e-10 at residual_rtol=1e-12, and no dependence at all on surface_rtol. Not a conservation error and not the fixed point; the diode's 1e-8 gate is a cold solve's luck rather than a promise |
| 2026-09-01 | Fermi-Dirac enters as a degeneracy factor multiplying the Boltzmann form, not as a replacement for it | Writing n = Nc F_{1/2}(eta) directly makes the intrinsic density come out as sqrt(Nc Nv) exp(-Eg/2V_T) = 1.0757e10, and this project anchors n_i at 1.0e10. Row 1 of the deviations table below records that the two are 7.6 percent apart and cannot both be primary, and it says the inconsistency bites the first time something computes a Fermi level from Nc. This is that moment. So the relation stays n = n_i exp(psi - phi_n) with a factor gamma = n/(Nc exp(eta)) on it, gamma is exactly 1.0 at zero density rather than 1.0 to rounding, and every nondegenerate result in the project is unchanged bit for bit. The n_i inconsistency stays exactly where it was instead of being smeared into the degenerate correction |
| 2026-09-01 | The generalized Einstein ratio is the term by term derivative of the same Joyce-Dixon series, not a separate approximation | D/(mu V_T) = u * deta/du exactly, so differentiating eta = ln(u) + sum A_k u^k gives 1 + sum k A_k u^k with no new coefficients. The alternative is evaluating 2 F_{1/2}/F_{-1/2} by quadrature at a numerically inverted eta, which costs two integrals per node per assembly and, worse, is a different approximation from the one the density used. Sharing the series makes the ratio and the inversion consistent by construction: the tangent of one is the other, which is what a Jacobian needs. Measured against Brent inversion of the integral, the closed form is 2.2e-4 relative at u = 4 and 4.4e-3 at u = 8 |
| 2026-09-01 | Joyce-Dixon refuses above n/Nc = 8 rather than extrapolating | The series is a fit and it eventually turns over. Measured against Brent inversion, relative error in n then in D/(mu V_T): 4.4e-5 and 2.2e-4 at u = 4, 9.0e-4 and 4.4e-3 at u = 8, 2.3e-3 and 1.1e-2 at u = 10, 4.1e-2 and 1.9e-1 at u = 20, and past u = 20 the Einstein ratio goes negative, which is a diffusivity pointing the wrong way. Eight is the last point where both are inside the 1 percent docs/04-validation.md asks for. It is 2.29e20 cm^-3, which clears the 1e20 source and drain with room, and a device that really is more degenerate than that should get a rational approximation rather than a silent extrapolation |
| 2026-09-01 | F_{1/2} is evaluated by fixed order Gauss-Legendre on x = t^2, not by adaptive quadrature | The substitution removes the square root branch point at the origin that would otherwise cost the rule most of its order, and the panel split at t = sqrt(eta) puts the shoulder of the occupancy on a panel boundary instead of in the middle of one. 96 nodes per panel returns F_{1/2} to 5e-15 relative against both the alternating series and scipy's adaptive quadrature, over eta in [-40, 40]. Fixed order rather than adaptive because the result has to be the same bits every time it is called at the same eta: an adaptive rule changes its subdivision under a perturbation, and a Jacobian entry derived from one is compared against complex step at 1e-10 |
| 2026-09-01 | Degeneracy will enter transport as an effective potential inside the Bernoulli argument, not as a generalized Einstein ratio multiplying D | The two are the same physics written two ways and doing both would double count. Writing n = n_i exp(psi - phi_n) gamma and defining psi_eff = psi + V_T ln(gamma) makes n exactly Boltzmann in psi_eff, so the flux is q mu (n dpsi_eff/dx - V_T dn/dx), which is the ordinary drift-diffusion form with D = mu V_T and the Scharfetter-Gummel exponential fit exactly valid in psi_eff. The generalized Einstein ratio D/(mu V_T) = u deta/du is the same statement made locally, and it holds because dln(gamma)/dln(u) = 1 - D/(mu V_T). docs/01-physics.md asks for the Einstein form; the effective potential form is chosen instead because it puts one term in one place, `_bernoulli_pair`, uses the same gamma the contacts and the equilibrium use, and leaves the Bernoulli argument the only thing that changes. Applying the ratio to D while leaving X = psi_right - psi_left would be a discretization error, not a modelling choice, because the exponential fit's decay rate is mu E / D and no longer 1/V_T |
| 2026-09-01 | The degenerate contacts and the degenerate Bernoulli argument have to land in one change, not two | The discrete equations enforce the Boltzmann relation exactly at equilibrium, so a contact carrying a Fermi-Dirac density and a Fermi-Dirac potential on a Boltzmann interior puts the whole 30.5 mV in a boundary layer one node wide. Measured on a 1e17 / 1e20 diode at equilibrium: ln(n) - psi is constant across all 201 nodes to 5.6e-17 and equal to exactly 0.0 at both contacts, and ln(p) + psi to 1.1e-16. That is the discretization holding n = n_i exp(psi) to the last bit, and it is what a half landed change would fight |
| 2026-09-09 | The density cap is applied to u itself in both directions, never by capping ln(u) and exponentiating | The forward path caps n/Nc at 8 by comparison and gets exactly 8.0. The inverse solves for w = ln(u), and capping w at ln(8) then exponentiating gives 7.999999999999998, one ulp below the ceiling. The slope helper returns zero at or above the ceiling and the series slope below it, so that one ulp made the Newton tangent 3.4 times too steep. Measured: at psi = 30 the inversion then converged linearly instead of in one step and the round trip ln(n) against the effective potential came back 0.306 out after six steps, against 0.0 exactly with the cap applied to u. The two directions have to cap by the same comparison or they are not inverses of each other |
| 2026-09-09 | Fermi-Dirac is a device level flag, off by default, and the NMOS is the only device that turns it on | It is a modelling choice rather than a number silicon has: the same silicon is degenerate or not depending on how heavily this device is doped.
