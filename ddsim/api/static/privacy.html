Privacy

Last updated 11 October 2026

Short version: there are no accounts, no cookies, no analytics and no ads. Here's everything the site touches.

What your browser keeps

One value in your browser's local storage, ddsim.welcome.seen, so the welcome panel doesn't open every time you visit. It never leaves your browser, and clearing your site data removes it.

What the server sees

When you press solve, the device settings you chose (sizes, doping, voltages, or the shape you drew) are sent to the server so it can run the simulation. They're held in memory while the job runs and for up to half an hour after it finishes, then dropped. They aren't written to disk or tied to who you are.

The site is hosted on Fly.io. Like any web host, Fly keeps standard request logs, which include your IP address, the time and the page requested. I use those only to keep the site running and to deal with abuse, and I don't sell or share them.

Saving devices

Saving a device downloads a JSON file straight to your computer. Loading one reads that file in your browser. I never receive a copy.

Everything else

The page loads all of its fonts and scripts from this site, not from third parties, so no other company sees your visit.

If you have a question, open an issue on the project's GitHub page.
